# Lab-3 Grubhub AI Instructions

## Purpose
A MySQL/Express/React academic prototype demonstrating a multi-tier architecture for a restaurant delivery system.

## Tech Stack
- **Frontend**: React (v19), Redux, Bootstrap
- **Backend**: Node.js (ESM), Express (v5), Sequelize, MySQL
- **Infrastructure**: MySQL

## Project Layout
- `/client/`: React frontend.
- `/server/`: Express backend.

## Run Instructions
- **Infrastructure**: `docker-compose up -d` (MySQL)
- **Install**: `npm install` at root.
- **Server**: `npm run start:server`
- **Client**: `npm run start:client`
